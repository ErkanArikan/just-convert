# Third-Party Licenses

This project bundles some third-party binaries and uses other user-installed dependencies. Command-line tools such as FFmpeg and qpdf remain unmodified external executables invoked as separate subprocesses and are not linked into the application code. The project's integration design treats each executable as a separate work, so invoking it across a process boundary does not by itself apply the executable's linking or derivative-work obligations to the calling source code; this is the project's compliance position for the bundled GPL v3 FFmpeg executable in particular, not legal advice. PDFium is a permissively licensed dynamic library loaded through a Rust binding. PDF-to-DOCX conversion runs in a separate worker executable that embeds Python, PyMuPDF, and pdf2docx; it is launched as a subprocess and not linked into the Rust core, so the project retains its own MIT or Apache-2.0 source licensing, while the worker as distributed is subject to PyMuPDF's AGPL v3 terms. LibreOffice is likewise embedded and run as a separate headless process. Each bundled component retains its original license, and its applicable license text and notices are reproduced in this directory.

On macOS and Linux, FFmpeg, qpdf, and PDFium are bundled too, from pinned and checksummed builds listed in `vendor/manifests/*.json` (`platformArchives`): FFmpeg 9.0.2 static GPL builds from [martin-riedl.de](https://ffmpeg.martin-riedl.de/) (macOS) and [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) (Linux), the official qpdf 12.4.2 release binaries, and PDFium from the same `chromium/7961` release as Windows. `pnpm fetch:engines` downloads and verifies them at build time; they are not committed. The Linux AppImage also carries the NSS and NSPR libraries (MPL 2.0) that LibreOffice links, copied from the build system; the `.deb` declares `libnss3` as a dependency instead.

Rows for Tesseract OCR and any other third-party component will be added when their integrations are introduced and their exact versions and distribution methods are known.

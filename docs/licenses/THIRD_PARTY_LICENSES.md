# Third-Party Licenses

This project bundles some third-party binaries and uses other user-installed dependencies. Command-line tools such as FFmpeg and qpdf remain unmodified external executables invoked as separate subprocesses and are not linked into the application code. The project's integration design treats each executable as a separate work, so invoking it across a process boundary does not by itself apply the executable's linking or derivative-work obligations to the calling source code; this is the project's compliance position for the bundled GPL v3 FFmpeg executable in particular, not legal advice. PDFium is a permissively licensed dynamic library loaded through a Rust binding. Python is launched as an external process for PDF-to-DOCX conversion, and that process imports user-installed PyMuPDF and pdf2docx packages; neither Python nor those packages is linked into or distributed with the Rust core or installer. The project applies the same optional external-dependency model to PyMuPDF that it applies to LibreOffice and retains its own MIT or Apache-2.0 source licensing. Each bundled component retains its original license, and its applicable license text and notices are reproduced in this directory.
